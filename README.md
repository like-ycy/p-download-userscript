# Pornhub 单个与当前页批量下载

安装文件：[`Pornhub-video-download-manager.user.js`](./Pornhub-video-download-manager.user.js)，当前版本 **2026.11.20.4**。原脚本保留不变。

## 安装

1. 在 Chrome 的 Tampermonkey 中新建脚本，把上述文件的全部内容粘贴进去并保存。
2. 停用旧的 **Pornhub video download with one click**，避免出现两套下载界面。
3. 刷新网站页面。若脚本没有运行，检查 Chrome 扩展设置中的“允许用户脚本”（旧版 Chrome 对应开发者模式）。
4. 使用新版 Chrome 和 **Tampermonkey 5.4 或更新版本**（需要本地 Blob/File 下载支持）。允许下载权限及 `mp4` 扩展名；下载模式可用“默认”或“浏览器 API”，不要禁用下载。首次访问媒体域名时，按油猴提示授权。

不依赖外部脚本库，也不需要本地服务、CDP 或 AppleScript；这些工具仅用于开发验证。

## 使用

| 页面 | 入口与行为 |
| --- | --- |
| 用户主页 | 显示“进入视频页下载”，提示主页只展示部分视频。 |
| 用户视频列表页 | 顶部设置画质，点击“选择下载”打开视频表格；每行右侧可下载单个，左侧勾选后顶部可下载多个。支持全选与取消全选。 |
| 视频播放页 | 播放器下方自动显示各画质的地址、复制和下载按钮，无需先点击展开。数据暂未就绪时会有限重试，也可手动刷新地址。 |

- 默认画质为 **1080p**。列表弹窗的单个和多选下载共用顶部画质；所选画质不可用时，自动选择不超过目标的最高画质。例如 2K（1440p）降到 1080p，720p 降到 480p。没有更低画质时跳过，不向上升级；任务显示实际画质及降级结果。
- 详情页各行明确下载该行画质；仍在真正下载时刷新地址。也保留“最低可用”和“最高可用”选项。
- 弹窗只列出打开时当前作者列表中已加载的视频，按 `viewkey` 去重，不扫描导航推荐，也不自动翻页。翻到下一页后可再选择下载；打开选择框本身不会下载视频或请求 40 个详情页。
- 任务串行执行，每个任务开始时重新获取签名地址。改动分辨率选项不会影响已加入的任务。
- “停止后续任务”停止排队项，当前正在解析或下载的任务继续完成；“继续已停止项”恢复这些排队项。“重试失败项”重新获取地址再尝试下载。
- 保持发起任务的标签页打开；读取媒体时不要刷新、翻页或关闭页面。刷新会丢失队列，下次开始下载时会清理未完成的临时文件。
- 文件名包含视频标题、视频标识和实际分辨率，避免不同画质使用同一个文件名。

## 地址与下载限制

媒体地址带签名、有效期，且可能绑定 IP 或请求环境。脚本的“复制最新地址”和“下载”都会重新解析，但不能保证复制到新标签页、另一个浏览器或另一个网络后仍可播放。

新版先使用页面 `fetch` 读取视频，逐块写入浏览器的私有临时磁盘（OPFS），然后把本地媒体交给 `GM_download` 保存。油猴不再重新请求签名 CDN 地址；本次已复现旧路径在 Tampermonkey 5.5.1 中返回 `unknown`，而页面读取及本地文件保存均正常。

脚本自身不在内存中积累整段视频；本地媒体显式标记为 `video/mp4`，避免 Chrome 把文件改成 `.txt`。不要求 `Content-Length`，有长度时会校验完整性；媒体连接连续 90 秒没有数据会失败，重试时重新下载。

临时磁盘需要可用空间，最终保存阶段还需要下载目录的空间，峰值可能接近视频大小的两倍。未知长度的媒体会持续写入，配额不足时停止并清理。成功、失败都会删除临时文件；刷新留下的文件会在下次下载时清理，其他标签页正在使用的临时文件由锁保护。油猴内部的文件传输和保存实现由管理器决定。

当前仅下载站点实际提供的 **MP4**。如果视频只有 HLS/m3u8，会明确提示不支持，不会把播放清单改名为 MP4。登录、站点验证、不可播放视频及 CDN 拒绝访问均会显示失败原因；脚本不改变这些访问条件。

已实测 `cn.pornhub.com/model/<作者>`、其 `/videos` 列表和 `/view_video.php?viewkey=...` 播放页。代码也识别 `pornstar`、`users`、`channels` 路径，但这些模板未逐一实测；遇到无法识别的作者列表会禁用批量按钮，避免下载推荐内容。
